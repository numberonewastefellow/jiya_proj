Demo Data Seeding

          

            Populate the database with the demo fixtures from server/seed/*.csv —
            5 demo users (alice, bob, eve, vendor.fresh, vendor.tech), 10 products, 7 orders, 3 fraud alerts,
            and 5 EventLog rows (prime the geo-anomaly demo for alice).
            Use Reseed for routine refreshes; Reset & reseed is destructive.
          


          

            

              
🌱 Reseed (safe, idempotent)

              

                Upserts users / products / orders / alerts and replaces marker-tagged seed events.
                Existing real user data, orders, and alerts are kept.
              

              
            

            

              
⚠️ Reset & reseed (destructive)

              

                Wipes all users, products, orders, fraud alerts, and EventLog rows,
                then reseeds from CSVs. You will be logged out — sign back in as
                admin@trackeasy.com / password123.
